# 界面设计说明（给设计者／给下一个接手的人）

这份文档是「把启动器做得像一件作品」的作业书。它不描述现有实现，而描述**目标**与**边界**：
照着它做，界面会有人味、有艺术性、有设计；不照着做，就会退回成一张设置表格。

---

## 1. 一句话定位

> 这不是一个「设置工具」，而是一张**摊在猎人梦境工作台上的羊皮纸**：它记录你的装备、你的战绩、
> 你今晚要去哪；所有开关都只是这张纸背面的铅笔批注。

判断标准：一个没玩过血源的人看到截图，应该先觉得「这东西有点味道」，其次才意识到它是个配置面板。

## 2. 必须守住的事实（否则做不出来）

| 事实 | 含义 |
|---|---|
| Tk/ttk，无 GPU 合成 | **没有真透明度**。渐隐只能用 stipple（网点），阴影只能用 1px 描边＋深色块 |
| 无真圆角 | 圆角要靠图片九宫格；代价高，默认**全直角**，靠留白和描线营造古典感 |
| 显示缩放 125% | 所有尺寸走 `px()`；任何硬编码像素在 4K 上会碎 |
| 中文字体只有 Microsoft YaHei UI / Noto Sans SC | 标题字体用 Georgia/Constantia（有衬线、有旧书感），中文正文用雅黑 |
| 单帧预算 | 任何动画一帧 ≤ 16 ms；页面切换总耗时 ≤ 120 ms（这是被真实卡顿教训换来的数字） |
| 素材只有玩家自己的 `pic1.png` | 不能内置封面（版权）；界面必须在**没有封面**时依然完整、依然好看 |

## 3. 美术方向

- **色**：近黑（`#07060a`）打底，暖灰面板（`#0f0d13`），卡片比面板亮一档（`#191520`）。
  强调色只有两个：铜金 `#d8b46a`（信息、装饰、悬停）与凝血红 `#8a1a1a`（唯一的行动色）。
  其余一律灰阶——**不要第三个颜色**，多一个就土。
- **光**：假想光源在左上，只允许「亮边」出现在上缘和左缘；阴影用 1px 深线，不用糊状阴影。
- **纹理**：允许极轻的网点（stipple `gray12`）做雾、做遮罩；禁止大面积噪点。
- **形**：直角、细线（1px）、大量负空间。装饰只用三种母题：菱形（标记）、短线（分隔）、四角取景框（画面）。
- **字**：拉丁标题全大写＋字距（`BLOODBORNE`、`SYSTEM`、`INFO`）；中文标题不加大字距，靠字号与金色区分层级。

## 4. 结构

```
┌ 侧栏 238px ─┬ 内容区 ─────────────────────────────┐
│ 品牌块       │ 页头：菱形 + 标题 + 副标题 + 金线     │
│ 游戏         │                                      │
│  · 开始      │ 卡片／分区（1px 描边，内边距 18-20）   │
│  · 图形      │  …                                   │
│ 系统         │                                      │
│  · …         │                                      │
│ 信息         │                                      │
├──────────────┴──────────────────────────────────────┤
│ 状态行（● 关键状态 · 分隔 · 关键状态）    PLAY 铜牌 │
└─────────────────────────────────────────────────────┘
```

- 分组不是装饰，是**认知地图**：玩家关心的（开始/图形/显示/游戏）在上，系统开关在中，关于/日志在下。
- 一屏只允许一个「主角」：开始页的主角是封面，其它页的主角是**当前分组的第一张卡**。
- 底部条永远只有两样东西：一句状态、一个动作。动作永远在右下角。

## 5. 组件规范

- **标题阶**：页标题 21px 衬线；分区标题 13px 衬线＋金色；卡片标题 12px 半粗；正文 10px；注释 9px 灰。
- **间距阶**：4 / 8 / 12 / 18 / 26 / 40。禁止出现 7、15、23 这种「手感数字」。
- **卡片**：`bg=CARD`、1px `LINE` 描边、内边距 18、标题下 1px 分隔线。
- **控件**：输入框与下拉用深底＋1px 描边，聚焦时描边变金；复选不要系统样式，自绘 14px 方框＋手绘勾。
- **按钮**：主按钮是唯一的红色块（渐变＋1px 金边），其余按钮是「描边幽灵按钮」。
- **链接**：金色下划线文字，`cursor=hand2`，悬停变亮一档。

## 6. 动效预算

只做三件事，且都必须能一键关掉（高级 → 界面动效）：

1. 导航悬停：6 帧、16 ms 一帧，只改一处背景与文字色。
2. 封面缓慢平移（Ken Burns）：11 fps、位移 2%/秒，**只在开始页运行**，离开即停。
3. 页头金线「画出来」：6 帧，只改一条线的宽度。

**禁止**：整窗淡入淡出（Tk 下每次都是全窗重绘，实测 0.3–2 秒）、列表逐项飞入、无意义的呼吸动画。

## 7. 文案语气

- 说人话，说结果，不说机制：「游戏版本 01.09：所有补丁可用」，不要「Patches 已加载」。
- 一句最多一个术语；不能解释的术语就换成玩家能验证的事实（「已安装 FSR 4 文件」）。
- 提示语只给**下一步**，不解释为什么（被用户否掉过两次的教训）。

## 8. 验收清单

- [ ] 1280×800 与 1920×1080 下都不裁切、不重叠，滚动条只在需要时出现。
- [ ] 没有封面时，开始页仍是有构图的（径向底＋字距标题），不是一块空白。
- [ ] 任何页面切换 ≤ 120 ms；启动 ≤ 800 ms；无卡顿白屏。
- [ ] 关掉界面动效后，没有任何后台定时器还在跑。
- [ ] 全中文界面里没有残留英文（专有名词、语言自称、按键字母除外）。
- [ ] 键盘可达：Tab 顺序合理，焦点可见（描边变金）。
- [ ] 灰度打印这张界面，层级依然清楚（说明你靠的是明度与留白，不是颜色）。
